7-Phase Album Checklist

Goal

Run every song through the same seven phases. Ticks reset on reload.

Phase 1: gain staging, routing, mix bus

Tracks: -12 to -10 dBFS Gain Staging Routing

Phase 2: drum foundation

drum_bus: -8 to -6 dBFS Drums

Phase 3: bass split & slammed sub

bass_bus: -8 to -6 dBFS Bass

Phase 4: guitars + first-chorus dial

instrument_bus: -6 to -5 dBFS Guitars Step B

Phase 5: lead vocals & BGVs

vocal_master: -6 to -5 dBFS Vocals

Phase 6: synths, strings, FX automation

print_bus: -4 to -3 dBFS Synths & SFX Orchestral FX Returns

Phase 7: tilt sweep, GClip, master print

master_bus: -8.5 to -7.5 LUFS Final print

Source: original WAP blueprint manual, 7-phase album checklist. Values synced to the Phase 3 setup and track pages.
