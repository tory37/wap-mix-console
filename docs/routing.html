Setup / 02

Folder & Bus Routing

Goal

Two-branch summing. INSTRUMENT BUS and VOCAL MASTER both feed PRINT / MIX BUS. Three silent hubs carry every sidechain.

Signal flow schematic

All instrument buses live in one parent folder, INSTRUMENT BUS ("ALL MUSIC"). All vocal tracks and vocal FX returns live in VOCAL MASTER. Both folders route into PRINT / MIX BUS.

Why two branches

Vocals never hit the instrument glue. Screams cannot pump the guitar wall. Muting VOCAL MASTER prints a clean instrumental in one pass.

Hub setup in REAPER

  1. Create the hub track

    Name it SC_KICK, SC_SNARE or SC_SPOTLIGHT.

  2. Uncheck Master/Parent Send

    Open the hub's Route window. The hub is now silent in the mix.

  3. Feed the hub

    Send the source track to the hub. Mode: Pre-Fader (Post-FX). Level: 0.0 dB.

  4. Set 4 channels on the target

    On the ducked track, set Track Channels from 2 to 4.

  5. Send hub to target

    Create a Pre-Fader (Post-FX) send. Audio: 1/2 to 3/4.

  6. Point the detector at 3/4

    ReaComp: Detector input = Auxiliary Input L+R. TDR Nova: Sidechain Input = EXT SC.

Track naming

Name every track in lowercase snake_case. The prefix tells you which bus the track feeds. Rendered stems then sort and read the same on every computer.

Rules

  • Use only lowercase a–z, 0–9, _ and -.
  • Never use \ / : * ? " < > |. Windows rejects them. Never end a name with a space or a dot.
  • No dots inside a name. Pro Tools reads .L and .R as channel tags.
  • Lowercase prevents case clashes. Linux is case-sensitive. macOS and Windows are not.
  • Zero-pad track numbers so files sort in session order: 01_kick_in.
  • Order fields broad to narrow: gtr_rhy_l. Related tracks then sort together.
  • Put song, version, tempo and sample rate on the folder, not the files: wap-song_name-v3-140bpm-48k/.
  • Render every stem from the same start to the same end.

REAPER render file name

Name the project file after the stem folder, for example wap-song_name-v3-140bpm-48k.rpp. Type the 01_ number into each track name. Then use this pattern in File > Render.

File name
$project\$track
  • $project is the project name. $track is the track name.
  • A backslash between wildcards makes a subfolder (Windows). Use a slash on Mac.
  • Entire project gives every stem the same start and end.
  • REAPER also has $tracknumber. Its help text says only "1 for the first track, 2 for the second". Zero-padding is unverified, so type the number into the name. Do not use both, or the number shows twice.
