Setup / 02

Folder & Bus Routing

Goal

Two-branch summing. instrument_bus and vocal_master both feed print_bus. Three silent hubs carry every sidechain.

Signal flow schematic

All instrument buses live in one parent folder, instrument_bus. All vocal tracks and vocal FX returns live in vocal_master. Instrument FX returns live in instrument_bus. Both folders route into print_bus. print_bus routes into master_bus, the top folder, which holds the mastering chain. The REAPER master stays empty, at unity.

Why two branches

Vocals never hit the instrument glue. Screams cannot pump the guitar wall. Muting vocal_master prints a clean instrumental in one pass.

Build the template

Whole layout in one run: ReaScript

The script builds every track, folder, send, hub, name and color on this page. It also sets the template pans and widths: panned mono sources get stereo pan mode with width 0%. It adds no plugins. The ggd_drums track gets 64 channels and 16 pre-fader sends into the kit tracks. Insert GetGood Drums on it. It never deletes a track. One undo step reverts it. Edit the TEMPLATE table at the top of the file to change the layout.

Update mode. Run it again on a project that already has template tracks, matched by exact name. The script lists every difference first: channels, parent send, color, spacer, pan, width, template fader levels, missing sends and missing tracks. Then it asks: apply all, review each change (Yes / No / Cancel), or stop. Missing tracks go in at the template level, so your own stem tracks keep their folders. It never deletes tracks or extra sends, never touches plugins, and never moves an existing track to another folder. The console lists what was applied and skipped, names used more than once, tracks in another folder than the template says, and tracks and sends not in the template.

If the project has tracks but none with a template name, the script asks first and adds the template after them.

Download wap_build_mix_template.lua

  1. Load the script

    Choose Actions > Show action list > New action > Load ReaScript. Select the downloaded file.

  2. Run it

    Run the action in a new project. The ReaScript console shows the track and send counts. Press Ctrl+Z to undo.

  3. Insert GetGood Drums

    Load the GGD kit on ggd_drums with 16 stereo outputs. Outputs 1/2 to 31/32 already feed the kit tracks.

Key sc_kick and sc_snare from the trigger tracks, not the kick or snare buses. Triggers hit at a constant level with no bleed, so the ducking stays consistent.

gtr_rhy_bus takes two keys. It has 6 channels: sc_snare lands on 3/4 and sc_spotlight on 5/6. Sharing one pair would sum both keys.

Hub setup in REAPER

  1. Create the hub track

    Name it sc_kick, sc_snare or sc_spotlight.

  2. Uncheck Master/Parent Send

    Open the hub's Route window. The hub is now silent in the mix.

  3. Feed the hub

    Send the source track to the hub: kick_smp to sc_kick, snr_smp to sc_snare. Mode: Pre-Fader (Post-FX). Level: 0.0 dB.

  4. Set 4 channels on the target

    On the ducked track, set Track Channels from 2 to 4.

  5. Send hub to target

    Create a Pre-Fader (Post-FX) send. Audio: 1/2 to 3/4.

  6. Point the detector at 3/4

    ReaComp: Detector input = Auxiliary Input L+R. TDR Nova: Sidechain Input = EXT SC.

Track naming

Name every track in lowercase snake_case. The prefix tells you which bus the track feeds. Rendered stems then sort and read the same on every computer.

Rules

  • Use only lowercase a–z, 0–9, _ and -.
  • Never use \ / : * ? " < > |. Windows rejects them. Never end a name with a space or a dot.
  • No dots inside a name. Pro Tools reads .L and .R as channel tags.
  • Lowercase prevents case clashes. Linux is case-sensitive. macOS and Windows are not.
  • Zero-pad track numbers so files sort in session order: 01_kick_sum.
  • Order fields broad to narrow: gtr_rhy_l. Related tracks then sort together.
  • Put song, version, tempo and sample rate on the folder, not the files: wap-song_name-v3-140bpm-48k/.
  • Render every stem from the same start to the same end.
  • Buses, returns and hubs follow the same rules: drum_bus, fx_hall, sc_kick.

REAPER render file name

Name the project file after the stem folder, for example wap-song_name-v3-140bpm-48k.rpp. Type the 01_ number into each track name. Then use this pattern in File > Render.

File name

  • $project is the project name. $track is the track name.
  • A backslash between wildcards makes a subfolder (Windows). Use a slash on Mac.
  • Entire project gives every stem the same start and end.
  • REAPER also has $tracknumber. Its help text says only "1 for the first track, 2 for the second". Zero-padding is unverified, so type the number into the name. Do not use both, or the number shows twice.
