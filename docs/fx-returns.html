FX Returns & soothe2 Matrix

Goal

Six named returns build one shared space. Every soothe2 instance runs with a raised low cut band. Never full-band default.

Why shared returns

  1. One space

    Drums, vocals and guitars share the same reverbs. The ear hears one room.

  2. Phase coherence

    Separate stereo reverbs on hard-panned rhythms wash out of phase across the center. They mask the snare and the vocal.

  3. Ducking

    A return can duck from a key. Tails drop 3–5 dB during fast parts and bloom in the gaps.

soothe2 rules

  1. Never leave the low cut band at 20 Hz

    The low cut band shapes what soothe2 reacts to. Full-band soothe2 reacts to sub and chugs. It pumps and guts the low end.

  2. Soft by default

    Soft keeps transients. Use Hard only for static artifacts, like a 3.2 kHz cab whistle.

  3. Oversample on render

    Set the offline rendering quality higher than real-time. Use 1x or 2x Oversample while mixing and 4x for the offline bounce unverified.

  4. Watch Depth

    Above 3.5 on guitars or vocals the source goes flat. The blueprint allows up to 4.5 on bright screams only.

  5. Keep Sharpness and Selectivity at 7 or below

    Higher values act like narrow comb filters. Sustained notes flange.

  6. Level-match

    soothe2 output is quieter. Trim the output before you compare bypass.
